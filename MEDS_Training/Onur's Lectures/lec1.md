# Digital Design and Computer Architecture

## L1: Intro: Fundamentals, Transistors, Gates

### The Transformation Hierarchy :

Problem -> Algorithm -> Program/Language -> System Software(VM, OS, MM) -> SW/HW Interfaces (ISA) -> Micro-Architechture -> logic(Gates etc) -> Devices -> Electrons

### Three Components Of Computer:

1. Computation
2. Communication
3. Storage/memory

### Transistor:

combination of Conductor(Metal), Insulator(Oxide) , SemiConductors
Types: n-type(Circuit completed when Voltage high , it pulls-down the output) , p-type(Circuit High when voltage low/zero, it pulls-up the output)
Modern Computer used Both : nMOS(n-type metal-Oxide Semiconductors) + pMOS(p-type metal-Oxide Semiconductors) = CMOS (Complementory Metal-Oxide Semiconductors)

### General CMOS Gate Structure

when transistor are in parallel, the network is ON if one of the transistor is ON
when transistor are in series, the network is ON if all transistors is ON
